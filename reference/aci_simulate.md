# Simulate a path from a model

The named verb for the package's
[`simulate.stochastic_model()`](https://biometryhub.github.io/ACI/reference/simulate.stochastic_model.md)
method. It exists so that the public surface reads as one family of
`aci_*` verbs. It is the same call, with the same arguments and the same
draws, and the S3 method stays registered on the
[`stats::simulate()`](https://rdrr.io/r/stats/simulate.html) generic, so
`simulate(model)` keeps working.

## Usage

``` r
aci_simulate(object, ...)
```

## Arguments

- object:

  A `stochastic_model` or `cgns_model` object.

- ...:

  Passed to the [`simulate()`](https://rdrr.io/r/stats/simulate.html)
  method: `nsim`, `seed`, `t_end`, `dt`, `ic`, `burn_in`, `keep_hidden`,
  `keep_noise`.

## Value

Whatever the method returns: an `aci_sim` object, or a list of them when
`nsim` exceeds one.

## See also

[`simulate.stochastic_model()`](https://biometryhub.github.io/ACI/reference/simulate.stochastic_model.md),
[`aci_model()`](https://biometryhub.github.io/ACI/reference/aci_model.md)
