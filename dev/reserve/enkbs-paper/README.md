# reserve/enkbs-paper — EnKBS-paper-backed, no MATLAB

**Currently empty.** Every EnKBS-family block excised for acir 0.1.0 has
`EnKBS-main/` MATLAB behind it and is filed in `reserve/enkbs/`. The one
paper-only fragment inside that family is `model_l96(preset = "legacy")`,
which `aci` labels "not in the four ACI papers or supplied MATLAB"
(`benchmark_models.R:471,477`); it is an inseparable arm of a
MATLAB-backed constructor, so it travels with
`reserve/enkbs/code/model_l96.R`.

The directory exists so the category is visible in the audit rather than
silently absent.
