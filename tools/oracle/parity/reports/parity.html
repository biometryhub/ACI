ref_filter_scalar ↔ aci_filter()

The forward CGNS filter. Note the reference's two initial conditions are literals inside the range: the mean starts at the true latent y(1), the covariance at a hardcoded 0.1. aciR takes both as arguments.

% Sum of Grammians of the observable process' noise feedbacks.
S_xoS_x = Sx_1^2 + Sx_2^2;
% Inverse of the sum of the observational noise coefficients' Grammians.
S_xoS_x_inv = 1/S_xoS_x;
% Sum of Grammians of the unobservable process' noise feedbacks.
S_yoS_y =  Sy_1^2 + Sy_2^2;
% Noise cross-interactions between the observable and unobservable processes.
S_yoS_x = Sy_1*Sx_1 + Sy_2*Sx_2;
S_xoS_y = S_yoS_x.';

% Posterior filter mean of the latent variable y.
filter_mean = zeros(1, N+1);
% Initial value of the posterior filter mean.
filter_mean(1) = y(1);
% Posterior filter covariance matrix of the latent variable y.
filter_cov = zeros(1, N+1);
% Initial value of the posterior filter covariance. Choosing a positive definite 
% matrix as to preserve the positive-definiteness of the posterior covariance 
% matrices over time.
filter_cov(1) = 0.1;

mu0 = filter_mean(1);
R0 = filter_cov(1);

for j = 2:N+1
    
    dx = x(j) - x(j-1);
    aux = S_yoS_x + filter_cov(j-1) * L_x(j-1);

    % Update the posterior filter mean and posterior filter covariance using the
    % optimal nonlinear filter state estimation equations for CGNSs; See Section 
    % 2.1.2 of the Supplementary Information.
    mu = mu0 + (L_y * mu0 + f_y(j-1)) * dt ...
             + aux * S_xoS_x_inv * (dx - (L_x(j-1) * mu0 + f_x(j-1)) * dt);
    R = R0 + (L_y * R0 + R0 * L_y + S_yoS_y - aux * S_xoS_x_inv * aux) * dt;
    
    filter_mean(j) = mu;
    filter_cov(j) = R;
    mu0 = mu;
    R0 = R;

end
R (aciR)aci-core.R :: aci_filter()
aci_filter <- function(x, comp, dt, mu0, R0) {
  if (.aci_is_mv(comp)) {
    x <- .aci_check_signal_mv(x)
    .aci_check_positive(dt, "dt")
    comp <- .aci_check_components_mv(comp, x)
    mu0 <- as.numeric(mu0)
    R0 <- as.matrix(R0)
    if (length(mu0) != nrow(R0) || nrow(R0) != ncol(R0)) {
      stop(
        "`mu0` and `R0` must share the unobserved dimension, with `R0` square.",
        call. = FALSE
      )
    }
    if (is.null(.aci_chol(R0))) {
      stop("`R0` must be symmetric positive definite.", call. = FALSE)
    }
    return(.aci_filter_mv(x, comp, dt, mu0, R0))
  }
  .aci_check_signal(x)
  n <- length(x)
  .aci_check_components(comp, n)
  .aci_check_positive(dt, "dt")
  .aci_check_scalar(mu0, "mu0")
  .aci_check_positive(R0, "R0")

  # ---- Forward recursion ----------------------------------------------------
  m <- numeric(n)
  v <- numeric(n)
  m[1L] <- mu0
  v[1L] <- R0
  inv <- 1 / comp$S_xoS_x
  L_y <- .aci_expand(comp$L_y, n)
  mu <- mu0
  R <- R0
  for (j in seq_len(n - 1L) + 1L) {
    dx <- x[j] - x[j - 1L]
    aux <- comp$S_yoS_x + R * comp$L_x[j - 1L]
    mu <- mu + (L_y[j - 1L] * mu + comp$f_y[j - 1L]) * dt +
      aux * inv * (dx - (comp$L_x[j - 1L] * mu + comp$f_x[j - 1L]) * dt)
    R <- R + (2 * L_y[j - 1L] * R + comp$S_yoS_y - aux * inv * aux) * dt
    if (!is.finite(R) || R <= 0) {
      .aci_stop_covariance("filter", j, (j - 1L) * dt, R)
    }
    m[j] <- mu
    v[j] <- R
  }
  list(mean = m, cov = v)
}

Findings

F1. The comparison horizon and the quadrature closure (closed)

The package's own harness for the causal influence range looped obs = j:(N+1), which is aciR's convention rather than the reference's, so every grading of that quantity had been taken against a harness sharing the convention under test. aci_cir() now takes horizon, and at the reference's value the subjective range agrees to 2.22e-16, against 1.16 time units at the default. The remaining 4.58e-09 on objective was the odd-interval Simpson closure. We had eliminated that hypothesis by argument rather than by measurement, and the argument held only for a full-record row, whose last entry is exactly zero; at the reference horizon it is 2.7e-04 of the peak. Adopting the reference's closure took objective to 1.37e-14, the maximum over the full reported region of both datasets, and removed a latent defect, since the previous panel assumed equal spacing on a logarithmic grid.

F2. The exact objective range was absent from aciR (fixed)

The reference computes the objective range in two ways, as an efficient underestimate and by its definition, and aciR implemented only the first. objective_exact now agrees with the reference's defn_objective_CIR to 1.59e-14. It cost less than we estimated, because an earlier report was wrong that .aci_simpson() assumed unit spacing. It always took an abscissa.

F6. The predator-prey script cannot be run from top to bottom

Fourteen blocks, seven for each causal direction, all assigning the same names. filter_mean is written for direction one and overwritten by direction two before anything consumes it, so a whole-script run computes the direction-one smoother from direction two's filter, silently and with plausible numbers. This is not a defect when the script is used as its own banners direct, one section at a time. It is a hazard for anyone automating it. Each direction is therefore composed from its own declared line ranges, guarded by a condition that holds in one direction only.

F7. Conditional ACI is enabled in three of the five ENSO scripts

This finding has been corrected three times, and only the present form was measured. The earlier answers came from reading source lines whose distinguishing feature is a comment marker. The present one comes from the observation-noise inverse that each script's filter actually consumed. With the per-step pseudoinverse live, S_xoS_x_inv varies from slice to slice and is dense; with it commented out and one diagonal entry overwritten, every slice from the second onward is the same matrix with exactly one non-zero entry. On that measurement h_W_unobs.m, T_C_unobs.m and u_unobs.m are conditional, while tau_unobs.m and u_h_W_tau_unobs.m are not. The hazard is greater than the earlier description of "one character of indentation" suggested, since two of the three live lines sit in column one. The consequence for this package is favourable. aci_conditional() has three upstream counterparts to be graded against, where the earlier reading had concluded there were none.

F9. The conditional scripts leave their first filter step unmasked

The pseudoinverse fills the first slice before the single target entry is overwritten, and the filter consumes that slice at j = 2. aciR masks every slice. Measured on h_W by running the same byte-verified extract twice and changing only its input, the filtered mean differs by 0.2376 at step 2, which is 73 % of the largest value that state ever reaches, and remains above 1e-6 for 6,256 of 20,001 steps. The difference is a transient, and it is not a small one. It is recorded now so that the eventual grading of aci_conditional() can match the convention deliberately, rather than reporting a difference of 0.238 as though it were a disagreement.

F8. The reference pseudo-inverts where aciR declines

The ENSO filter forms pinv(S_x * S_x'), a Moore-Penrose pseudoinverse the authors chose for stability. aciR uses a Cholesky inverse and requires positive-definiteness at every slice, so on a singular slice the reference continues where aciR stops. This is a difference in behaviour rather than in implementation, and it is documented rather than repaired. A quantitative comparison of the two inverses over the ENSO slices appeared here previously. It has been withdrawn, because no artefact in reports/ supports those figures, and a number that has not been measured does not belong on this page. Re-measuring it is open work, and the probe needed is a short one.

F3, F4 and F5. A silent empty range, a vacuous pass, and three interface asymmetries

The reference's exact objective CIR evaluates to an empty range rather than erroring on a short window. This harness contained an instance of the same fault, now fixed. An empty comparison reported ok for having compared nothing, because max(numeric(0)) is -Inf. It is now a named failure, and it fired on the next run.
