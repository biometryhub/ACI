ref_filter_scalar ↔ aci_filter()

The forward CGNS filter. Note the reference's two initial conditions are literals inside the range: the mean starts at the true latent y(1), the covariance at a hardcoded 0.1. aciR takes both as arguments.

MATLAB (reference)dyad_interaction_model.m:131-172
% Sum of Grammians of the observable process' noise feedbacks.
S_xoS_x = Sx_1^2 + Sx_2^2;
% Inverse of the sum of the observational noise coefficients' Grammians.
S_xoS_x_inv = 1/S_xoS_x;
% Sum of Grammians of the unobservable process' noise feedbacks.
S_yoS_y =  Sy_1^2 + Sy_2^2;
% Noise cross-interactions between the observable and unobservable processes.
S_yoS_x = Sy_1*Sx_1 + Sy_2*Sx_2;
S_xoS_y = S_yoS_x.';

% Posterior filter mean of the latent variable y.
filter_mean = zeros(1, N+1);
% Initial value of the posterior filter mean.
filter_mean(1) = y(1);
% Posterior filter covariance matrix of the latent variable y.
filter_cov = zeros(1, N+1);
% Initial value of the posterior filter covariance. Choosing a positive definite 
% matrix as to preserve the positive-definiteness of the posterior covariance 
% matrices over time.
filter_cov(1) = 0.1;

mu0 = filter_mean(1);
R0 = filter_cov(1);

for j = 2:N+1
    
    dx = x(j) - x(j-1);
    aux = S_yoS_x + filter_cov(j-1) * L_x(j-1);

    % Update the posterior filter mean and posterior filter covariance using the
    % optimal nonlinear filter state estimation equations for CGNSs; See Section 
    % 2.1.2 of the Supplementary Information.
    mu = mu0 + (L_y * mu0 + f_y(j-1)) * dt ...
             + aux * S_xoS_x_inv * (dx - (L_x(j-1) * mu0 + f_x(j-1)) * dt);
    R = R0 + (L_y * R0 + R0 * L_y + S_yoS_y - aux * S_xoS_x_inv * aux) * dt;
    
    filter_mean(j) = mu;
    filter_cov(j) = R;
    mu0 = mu;
    R0 = R;

end

aci_filter <- function(x, comp, dt, mu0, R0) {
  if (.aci_is_mv(comp)) {
    x <- .aci_check_signal_mv(x)
    .aci_check_positive(dt, "dt")
    comp <- .aci_check_components_mv(comp, x)
    mu0 <- as.numeric(mu0)
    R0 <- as.matrix(R0)
    if (length(mu0) != nrow(R0) || nrow(R0) != ncol(R0)) {
      stop(
        "`mu0` and `R0` must share the unobserved dimension, with `R0` square.",
        call. = FALSE
      )
    }
    if (is.null(.aci_chol(R0))) {
      stop("`R0` must be symmetric positive definite.", call. = FALSE)
    }
    return(.aci_filter_mv(x, comp, dt, mu0, R0))
  }
  .aci_check_signal(x)
  n <- length(x)
  .aci_check_components(comp, n)
  .aci_check_positive(dt, "dt")
  .aci_check_scalar(mu0, "mu0")
  .aci_check_positive(R0, "R0")

  # ---- Forward recursion ----------------------------------------------------
  m <- numeric(n)
  v <- numeric(n)
  m[1L] <- mu0
  v[1L] <- R0
  inv <- 1 / comp$S_xoS_x
  L_y <- .aci_expand(comp$L_y, n)
  mu <- mu0
  R <- R0
  for (j in seq_len(n - 1L) + 1L) {
    dx <- x[j] - x[j - 1L]
    aux <- comp$S_yoS_x + R * comp$L_x[j - 1L]
    mu <- mu + (L_y[j - 1L] * mu + comp$f_y[j - 1L]) * dt +
      aux * inv * (dx - (comp$L_x[j - 1L] * mu + comp$f_x[j - 1L]) * dt)
    R <- R + (2 * L_y[j - 1L] * R + comp$S_yoS_y - aux * inv * aux) * dt
    if (!is.finite(R) || R <= 0) {
      .aci_stop_covariance("filter", j, (j - 1L) * dt, R)
    }
    m[j] <- mu
    v[j] <- R
  }
  list(mean = m, cov = v)
}

Until horizon existed this comparison could not be made: the harness put aciR's whole-record answer beside the reference's truncated one and called the gap a disagreement, when they are answers to different questions. Rows marked by design report aciR's default behaviour with its magnitude, so the size of the design choice is on the record rather than hidden.

Findings

F1 — the CIR horizon and quadrature (closed)

The package's own CIR harness looped obs = j:(N+1) — aciR's convention, not the reference's — so every CIR grading the package owned was taken against a harness sharing the convention under test. aci_cir() now takes horizon; with the reference's value the subjective range agrees to 2.22e-16, against 1.16 time units at the default. The remaining 4.58e-09 on objective was the odd-interval Simpson closure after all — I had eliminated that hypothesis by argument rather than by measurement, and the argument held only for a full-record row, whose last entry is exactly zero. At the reference horizon it is 2.7e-04 of the peak. Adopting the reference's closure took objective to 1.37e-14, the maximum over the full reported region of both datasets, and removed a latent defect: the old panel assumed equal spacing on a logarithmic grid.

F2 — the exact objective CIR was absent from aciR (fixed)

The reference computes the objective range both as an efficient underestimate and by its definition; aciR implemented only the first. objective_exact now agrees with the reference's defn_objective_CIR to 1.59e-14. It came cheaper than estimated, because the earlier report was wrong that .aci_simpson() assumed unit spacing — it always took an abscissa.

F6 — the predator-prey script cannot be run top to bottom

Fourteen blocks, seven per causal direction, all assigning the same names. filter_mean is written for direction one and overwritten by direction two before anything consumes it, so the direction-one smoother reads direction two's filter — silently, with plausible numbers. Each direction is therefore composed from its own declared line ranges, guarded by a condition that holds in one direction only.

F7 — conditional ACI is enabled in exactly one of the five ENSO scripts

In h_W_unobs.m, S_xoS_x_inv(1,1,:) = 1/sigma_C^2; is live code: it carries leading whitespace rather than a comment marker, among five comment lines that read as guidance. Its four siblings leave the equivalent line commented. So one script answers h_W → T_C | (u,T_E,τ,I) where the others answer the unconditional question, distinguished by one character of indentation. A reproducibility hazard in the reference, and a correction to this finding's own earlier wording, which claimed no executable counterpart existed.

F8 — the reference pseudo-inverts where aciR refuses

Measured rather than argued: pinv and a Cholesky inverse differ by at most 1.14e-13 over 2001 ENSO slices, worst condition number 397.5, and Cholesky refused none of them. aciR is the stricter route and is never driven to failure on this data.

F3, F4, F5 — a silent empty, a vacuous pass, and three interface asymmetries

The reference's exact objective CIR evaluates to an empty range rather than erroring on a short window. This harness had the same disease and it was fixed: an empty comparison reported ok for having compared nothing, because max(numeric(0)) is -Inf. It is now a named failure, and it fired on the next run.
