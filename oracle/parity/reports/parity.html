ref_filter_scalar ↔ aci_filter()

The forward CGNS filter. Note the reference's two initial conditions are literals inside the range: the mean starts at the true latent y(1), the covariance at a hardcoded 0.1. aciR takes both as arguments.

% Sum of Grammians of the observable process' noise feedbacks.
S_xoS_x = Sx_1^2 + Sx_2^2;
% Inverse of the sum of the observational noise coefficients' Grammians.
S_xoS_x_inv = 1/S_xoS_x;
% Sum of Grammians of the unobservable process' noise feedbacks.
S_yoS_y =  Sy_1^2 + Sy_2^2;
% Noise cross-interactions between the observable and unobservable processes.
S_yoS_x = Sy_1*Sx_1 + Sy_2*Sx_2;
S_xoS_y = S_yoS_x.';

% Posterior filter mean of the latent variable y.
filter_mean = zeros(1, N+1);
% Initial value of the posterior filter mean.
filter_mean(1) = y(1);
% Posterior filter covariance matrix of the latent variable y.
filter_cov = zeros(1, N+1);
% Initial value of the posterior filter covariance. Choosing a positive definite 
% matrix as to preserve the positive-definiteness of the posterior covariance 
% matrices over time.
filter_cov(1) = 0.1;

mu0 = filter_mean(1);
R0 = filter_cov(1);

for j = 2:N+1
    
    dx = x(j) - x(j-1);
    aux = S_yoS_x + filter_cov(j-1) * L_x(j-1);

    % Update the posterior filter mean and posterior filter covariance using the
    % optimal nonlinear filter state estimation equations for CGNSs; See Section 
    % 2.1.2 of the Supplementary Information.
    mu = mu0 + (L_y * mu0 + f_y(j-1)) * dt ...
             + aux * S_xoS_x_inv * (dx - (L_x(j-1) * mu0 + f_x(j-1)) * dt);
    R = R0 + (L_y * R0 + R0 * L_y + S_yoS_y - aux * S_xoS_x_inv * aux) * dt;
    
    filter_mean(j) = mu;
    filter_cov(j) = R;
    mu0 = mu;
    R0 = R;

end

aci_filter <- function(x, comp, dt, mu0, R0) {
  if (.aci_is_mv(comp)) {
    x <- .aci_check_signal_mv(x)
    .aci_check_positive(dt, "dt")
    comp <- .aci_check_components_mv(comp, x)
    mu0 <- as.numeric(mu0)
    R0 <- as.matrix(R0)
    if (length(mu0) != nrow(R0) || nrow(R0) != ncol(R0)) {
      stop(
        "`mu0` and `R0` must share the unobserved dimension, with `R0` square.",
        call. = FALSE
      )
    }
    if (is.null(.aci_chol(R0))) {
      stop("`R0` must be symmetric positive definite.", call. = FALSE)
    }
    return(.aci_filter_mv(x, comp, dt, mu0, R0))
  }
  .aci_check_signal(x)
  n <- length(x)
  .aci_check_components(comp, n)
  .aci_check_positive(dt, "dt")
  .aci_check_scalar(mu0, "mu0")
  .aci_check_positive(R0, "R0")

  # ---- Forward recursion ----------------------------------------------------
  m <- numeric(n)
  v <- numeric(n)
  m[1L] <- mu0
  v[1L] <- R0
  inv <- 1 / comp$S_xoS_x
  L_y <- .aci_expand(comp$L_y, n)
  mu <- mu0
  R <- R0
  for (j in seq_len(n - 1L) + 1L) {
    dx <- x[j] - x[j - 1L]
    aux <- comp$S_yoS_x + R * comp$L_x[j - 1L]
    mu <- mu + (L_y[j - 1L] * mu + comp$f_y[j - 1L]) * dt +
      aux * inv * (dx - (comp$L_x[j - 1L] * mu + comp$f_x[j - 1L]) * dt)
    R <- R + (2 * L_y[j - 1L] * R + comp$S_yoS_y - aux * inv * aux) * dt
    if (!is.finite(R) || R <= 0) {
      .aci_stop_covariance("filter", j, (j - 1L) * dt, R)
    }
    m[j] <- mu
    v[j] <- R
  }
  list(mean = m, cov = v)
}

The rows that exceed are not failures of either implementation. They are one mechanism: for each reporting time the reference integrates and searches the lagged sequence only as far as last_idx, where aciR runs to the end of the record. Restricted to the region the reference itself reports, the peak divergence agrees to 9.28e-15. The consequence is that aciR cannot presently reproduce the published CIR figures, because it has no argument with which to adopt the reference's horizon.

Findings

F1 — the CIR horizon, and an oracle that shared the convention under test

The package's own CIR harness loops obs = j:(N+1) — aciR's convention, not the reference's. Every CIR grading the package owns was taken against a harness sharing the convention being tested, so this divergence was structurally invisible to it. Repair specified, not applied: it changes an exported signature.

F2 — the exact objective CIR is absent from aciR

The reference computes the objective range both as an efficient underestimate and by its definition. aciR implements the first and documents the second. This corrects an earlier claim that capability parity was complete.

F6 — the predator-prey script cannot be run top to bottom

Fourteen blocks, seven per causal direction, all assigning the same names. filter_mean is written for direction one and overwritten by direction two before anything consumes it, so the direction-one smoother reads direction two's filter — silently, with plausible numbers. Each direction is therefore composed from its own declared line ranges, guarded by a condition that holds in one direction only.

F7 — conditional ACI has no executable counterpart upstream

The ENSO script's conditional-ACI section is commented guidance, telling the reader which single line to substitute by hand. There is nothing to extract and nothing to grade against, so aci_conditional() is absent-upstream rather than pending. Alongside it, the reference pseudo-inverts the observation-noise Grammian where aciR requires positive-definiteness at every slice and refuses — a system the reference will analyse, aciR declines.

F3, F4, F5 — a silent empty, a vacuous pass, and three interface asymmetries

The reference's exact objective CIR evaluates to an empty range rather than erroring on a short window. This harness had the same disease and it was fixed: an empty comparison reported ok for having compared nothing, because max(numeric(0)) is -Inf. It is now a named failure, and it fired on the next run.
